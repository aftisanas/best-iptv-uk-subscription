## Network positioning rules (avoid cannibalization)
- This site (best-iptv-uk-subscription.com) owns the buyer's-guide / evaluation angle
- cheap-iptv.tv owns the price/value angle (already live)
- fast-iptv.tv owns the speed/quality angle (already live)
- This site must NOT target: "cheap", "cheapest", "discount", "budget", "fast", "fastest", "no buffering", "low latency"
- This site SHOULD target: "best", "top", "recommended", "review", "guide", "criteria", "compare", "evaluation"

## Compliance rules (universal)

Banned broadcaster/league/legal terms — see master list, but in summary:
- No Sky, BBC, ITV, Channel 4, Channel 5, BT Sport, TNT Sports, Premier League, Champions League, F1, NFL, UFC etc.
- No "100% legal", "fully licensed", "Ofcom-approved"
- No "#1 Rated", "Voted Best", "Top Rated", "leaderboard", "Trustpilot Average"
- Generic substitutions:
  - "Premier League" → "top-tier UK football"
  - "Sky" (in comparison) → "traditional UK pay-TV"  
  - "Netflix/Disney+" → "popular streaming platforms"
  - "BBC/ITV/Channel 4" → "UK terrestrial channels"
  - "F1" → "motorsport"
